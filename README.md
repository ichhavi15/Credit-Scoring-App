# 💳 Credit Scoring App

### AI-Powered Loan Approval System

A machine learning-based application designed to evaluate loan applications and support credit risk assessment using applicant information and banking rules.

## 🎯 Project Overview

The Credit Scoring App helps assess loan eligibility by analysing applicant details and predicting creditworthiness.

## ✨ Key Features

- Loan eligibility assessment
- Machine learning-based credit evaluation
- Credit risk analysis
- User-friendly application interface
- Data-driven decision support

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Streamlit

## 📂 Project Structure

- `app.py` – Application interface
- `main.py` – Main application logic
- `loan_data.csv` – Loan dataset
- `requirements.txt` – Project dependencies

## 🚀 How to Run

1. Clone this repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

## 🎓 Project Objective

To explore how machine learning can support financial institutions in evaluating loan applications and making data-driven credit decisions.
